# MATE project page

This is the local static site draft for the MATE project page.

## Preview

Serve this directory with any static server, for example:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Current media

The page includes local copies of the teaser, pipeline, full narrated demo, task montage, collection-efficiency clip, policy rollout, EAIS visualization, sim-to-real transition, and real-world demo.

## Before publishing

- Confirm the final author list and affiliations.
- Add Paper, Code, and Dataset links only after they are public.
- Replace the placeholder footer with the final project/repository links.
- Deploy to a personal repository first; later transfer or mirror this site to `4dvlab/MATE_page`.

For local video seeking, use python serve.py instead of the basic Python HTTP server.
